# hamy.cz

Static site for [hamy.cz](https://www.hamy.cz/). English-only personal pages: Michal Hamerník, plus the Interval Training Android app.

This repository is public to read. Only [HamyCZ](https://github.com/HamyCZ) may push or merge. Issues and pull requests are not accepted.

## What is intentionally not here

FTP credentials, deploy scripts, and `.htaccess`. Do not add `.env` files, passwords, or private keys.
